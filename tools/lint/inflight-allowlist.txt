# inflight-single-source 豁免表
# 格式（每行一条）：<相对 entry/src/main/ets/ 的路径>|<API 标签> # <理由（必填，≥8 字符）>
#
# ⛔ 理由必填：缺 `#` 或理由过短（去空白后 <8 字符）的条目**不生效**（该命中仍然判红），
#    并会在门禁输出里单列为「无效豁免」。想豁免就必须说清"为什么它不是第二个在飞动效"。
#
# ⛔ 请勿在此登记"待修"项 —— 修不动的应在裁决后**修掉**，而不是长期豁免（豁免是给
#    "经设计裁决、语义上确实不是装饰性在飞动效"的用法）。
#
# 可用标签（与脚本判据表一致）：
#   SymbolEffect(循环类) / iterations>1 / playMode / 内置连续动画组件 / 内联过渡(非底座)
#
# 示例（默认注释掉；有需要时按上面格式启用）：
# components/AuthImage.ets|内置连续动画组件 # 图片加载中的进度指示器，非装饰性在飞动效
