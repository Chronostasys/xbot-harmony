# xbot 1.0.0 发布说明

## 本次发布

- ArkTS/ArkUI 原生 HarmonyOS 客户端，连接用户自建的 xbot 服务端。
- 支持会话列表、流式对话、工具调用状态、迭代历史、上下文用量、设置与插件。
- 支持实况窗（前台本地更新；后台服务端更新取决于 Push Kit 权益）。
- 支持插件：鸿蒙通知推送（`push_harmony_noti`）与实况窗推送（`push_harmony_liveview`）。

## 已知限制

- 服务端地址由用户在登录页填写；AppGallery 审核必须提供可公网访问的审核环境与测试账号。
- Push Kit 普通通知需要 AGC「精准推送能力」与消息分类权益；实况窗服务端更新需要「实况窗正式权益」。
- 首次冷启动、切换会话、弱网重连会从服务端权威历史重新对齐；不提供本地会话历史缓存。

## 提审前必须填写

- 版本号/版本说明
- 公网 API 地址与测试账号
- 隐私政策公网 URL
- AppGallery 截图（建议 3–5 张：对话、工具执行、实况窗、设置）
