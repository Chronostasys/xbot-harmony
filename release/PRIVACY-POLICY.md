# xbot 隐私政策（提审草稿）

> 这是一份需要由运营主体审核并发布到公网 HTTPS URL 的草稿，不构成法律意见。AppGallery 要求隐私政策可从应用内或商店页访问。

## 1. 我们处理的数据

xbot 是连接用户自有 xbot 服务端的客户端。为实现对话与工具执行，应用会处理：

- 用户在登录页填写的服务端地址、账号与登录令牌；
- 用户主动输入的对话内容、代码片段、附件名称/大小；
- 服务端返回的会话、工具执行状态、上下文用量与实况窗状态；
- 设备 Push Token（仅在用户启用鸿蒙推送并登记时）。

应用不读取通讯录、短信、精确位置、相册（用户主动选择文件除外）。

## 2. 数据用途

- 连接用户指定的 xbot 服务端并完成登录；
- 发送用户主动提交的消息、接收回复和工具状态；
- 在用户启用时登记 Push Token，用于任务完成通知/实况窗；
- 本地保存登录状态和用户界面偏好。

## 3. 数据共享

数据发送到用户自行配置的 xbot 服务端；该服务端由用户或服务提供方部署。应用本身不包含广告 SDK，不向第三方出售个人信息。

## 4. 数据存储与删除

登录令牌和界面偏好保存在设备本地；会话内容由用户配置的服务端保存。用户可在应用内退出登录/删除本地数据，服务端数据删除以服务端能力为准。

## 5. 权限

- `ohos.permission.INTERNET`：连接用户配置的服务端；
- `ohos.permission.GET_NETWORK_INFO`：网络状态提示；
- `ohos.permission.VIBRATE`：本地操作反馈。
