样张 3 · 开屏 + logo（白色主题不靠发光；安全区与对比度标注）

依据 docs/REDESIGN-INPUT-BRAND.md 的四条结构性断层：① 开屏色在资源层取不到 token； ② 开屏跟系统深浅（白主题必跳色）；③ 图标静态单层、尾巴超安全区（实算 393.9 > 313）； ④ 品牌紫 ≠ porcelain 的 Apple Blue。本设计给出 brand.* / splash.* 语义角色 + 降级链。

① 白色主题开屏 —— 实心标记 on 中性白（⛔ 零发光）

xbot
底 = splash.canvas.light（与首帧画布 逐字节一致，消冷启动跳色）。
标记 = brand.primary 实心 glyph（此处示意 Apple Blue，见未决 #4）；零 glow / 零渐变。
橙色虚圈 = 分层图标前景安全区 ≤313；绿色虚圈 = 建议标记最大半径 ≤410（0.8×512）。

② 深色启动器/开屏 —— 满幅品牌色 + 反色 glyph

xbot
底 = splash.canvas.dark；标记 = 反色 glyph（brand.onPrimary）压 brand.primary。
同一几何真源 core/brand.ets（bubblePath()/starPath()）—— 设计改了只改这里。

③ 降级链（从满幅色 → 单色轮廓 → wordmark）

1. 满幅品牌色
2. 实心标记 on 中性白（白主题）
3. 单色轮廓（极端降级/无障碍）
xbot
4. 纯文字 wordmark
⛔ 白色主题下禁用发光/渐变（glowSoft 在白底几乎不可见；CTA 渐变最亮端白字只有 2.09:1）。

⑤ 开屏 → 主界面：一次性过渡（⛔ 不与"在飞=光球"并存）

A. 系统开屏（静态标记 + startWindowBackground）→ 系统决定
B. 标记入场：scale 0.92→1 + opacity 0→1，一次 → motion.enterBlock = 220ms
C. 让位主界面：opacity 1→0 上移消隐 → motion.transition = 320ms
reduceMotion = true ⇒ 直接静态呈现（§4.3）；⛔ 呼吸/脉冲不属于开屏（那是"在飞"的语言）。
