03 · 工具与状态（静态样张）

这张图在证明什么
· 工具一行只用一个语义档驱动四列（形态 / 名称 / 状态色 / chip 文案）—— 六档（排队·生成中·执行中·失败·已终止·完成）互不打架；
· 抹掉颜色（灰阶）后仍能区分六档 —— 这是"色盲可用"的可视化（对应门禁 tools/tests/tool_legibility.test.ts）；
· pill / chip / 浮层是三个不同层级的"面"（surface.pill · surface.chip · surface.overlay）—— 浅色/纯白主题下也能看出层次（chip 恒为"内嵌凹槽"）；
· 全图零动效：唯一的"在飞"动效 = 光球（本图之外）；其余最多是一次性过渡（走 anim.ets）—— 克制与否，一眼可判；
· 所有数值均为令牌层真值（旁注 token 名）；令牌层没有的，标 缺 token，没有临时编值。

图例：无动效 / 一次性过渡 anim.ets / 在飞 = 光球（唯一）
